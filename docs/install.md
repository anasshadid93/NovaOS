# Installing NovaOS

## The short way (Debian/Ubuntu)

```sh
curl -fsSL https://raw.githubusercontent.com/anasshadid93/NovaOS/main/deploy/get.sh | sudo bash
```

`deploy/get.sh` installs the packages it needs (git, ffmpeg, 7z, restic, smartmontools, Node.js 22 from NodeSource,
Docker from Ubuntu's repo, Tailscale), copies the code to `/opt/minismanager`, builds it as the service user
(the user who ran `sudo`, or a new system user `manar`), then runs `deploy/install.sh`. At the end it prints the
address and the first-run token. Open the address on your phone, enter the token, and the setup wizard asks for
the name, address, time zone and big drive, then creates your account.

Environment variables: `MANAR_USER`, `MANAR_DIR`, `MANAR_DATA_ROOT`, `MANAR_REPO`, `MANAR_REF`, `MANAR_NO_DOCKER=1`,
`MANAR_NO_TAILSCALE=1` (bring your own HTTPS reverse proxy to `127.0.0.1:7470`). Running the line again updates in place.

## By hand

### 1. The app itself
```sh
npm ci && npm run build
sudo deploy/install.sh --user "$USER" [--data-root /srv/data] [--port 7470] [--https-port 7443] [--no-tailscale]
```
- Installs `/usr/local/sbin/manar-helper` (root:root 0755) with the user and data root filled in.
- Installs `/etc/sudoers.d/manar` (one `NOPASSWD` line for the helper, checked with `visudo`).
- Installs and starts `manar.service` (runs as that user, listens on `127.0.0.1:7470`).
- Creates `<data-root>/{apps,files,external}` and adds the user to the `docker` group.
- Adds `tailscale serve --https=7443` and leaves the existing serve entries untouched.
- Prints the first-run setup token. Open the printed address on the phone and enter it.

Undo: `sudo deploy/install.sh --uninstall`. Data in `var/` is kept.

### 2. Docker for the app store
Docker (with compose v2) must be installed and the service user must be in the `docker` group. Put
`"ip": "127.0.0.1"` in `/etc/docker/daemon.json` so published ports stay on localhost: apps are reached
through `tailscale serve` or your reverse proxy, never straight from the LAN. `deploy/get.sh` does all of this.

### 3. Optional packages
- `sudo apt install smartmontools` turns on SMART data on the Disks screen.
- `ufw` is not installed. The Firewall screen only reads its status, so install and configure it yourself if you want it.

### Moving NovaOS to another folder or machine

Everything NovaOS is — phone app, desktop mode, server, database (`var/manar.db`),
thumbnails and settings — lives in this one folder. Nothing in it points at its own location.

```bash
sudo systemctl stop manar
mv /path/to/manar /new/place/manar        # or copy it to another machine
cd /new/place/manar && npm ci && npm run build
sudo deploy/install.sh --user "$USER"      # rewrites the service, helper and sudoers for the new path
```

Outside the folder, by design (they belong to the server, not to NovaOS):

| Where | What |
|---|---|
| `/srv/data` | your files (Files, Gallery, the desktop's `files/Desktop`, `files/Downloads`) |
| `/srv/apps/<id>` | apps installed from the store (their compose files) |
| `~/ArtCraft` | the ArtCraft apps (`MANAR_CRAFT_DIR` to change) |
| `/usr/local/sbin/manar-helper`, `/etc/sudoers.d/manar`, `/etc/systemd/system/manar.service` | generated by `deploy/install.sh` from this folder |
